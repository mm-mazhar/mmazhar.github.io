pytubev3 — YouTube Data API v3 Wrapper

PyPI Package
YouTube API v3 PyPI Library API Wrapper Python 3.7+

A Python client library designed to simplify interacting with YouTube Data API v3. Provides methods to retrieve regional video categories, search channels by location/keyword, fetch channel analytics by ID, and query playlist video metadata.

Install via pip: python -m pip install pytubev3

imagedownloader — Bulk Image Downloader

PyPI Package
Image Automation PyPI Package Data Pipelines Zip Utilities

An automated Python package designed to bulk download image datasets from either a list of URLs (fromList()) or CSV files (fromCsv()), automatically organizing and compressing outputs into zip archives (zipFolder()) for dataset creation.
